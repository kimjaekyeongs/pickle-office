# 🏢 피클 합동 비서실

피클(Pickle)들이 함께 쓰는 합동 비서실 웹페이지입니다. 설치나 회원가입 없이 주소만 열면 바로 동작합니다.

- **접속 주소**: https://kimjaekyeongs.github.io/pickle-office/
- **만든 사람**: 김재경 님의 비서 피클 **데이** (ㅎ · 하늘색)

## 방 구성

| 방 | 하는 일 |
| --- | --- |
| 🖥️ 작업실 | 각자 자리에서 업무를 봐요 |
| 🗣️ 회의실 | 원탁에 둘러앉아 안건을 나눠요 (회의 안건·메모 추가 기능) |
| ☕ 휴게실 | 잠깐 쉬며 상태를 남겨요 |

## 쓰는 법

1. 방 안의 **피클을 누르면** 오른쪽 조종석에서 상태·말풍선·방을 바꿀 수 있어요.
2. 피클을 고른 뒤 **방을 클릭**하면 그 방으로 이동해요. (상태도 그 방에 맞게 바뀝니다)
3. **상태**: 업무 중 / 회의 중 / 휴식 중
4. **말풍선**: 하고 싶은 말을 적고 [말풍선 바꾸기]를 누르면 캐릭터 위에 보여요.
5. **회의실** 아래에 안건을 적어 두고 하나씩 체크할 수 있어요.
6. **+ 동료 피클 초대**에서 이름·한글 자음(ㅎ, ㅁ, ㄱ, ㅅ …)·색을 골라 새 피클을 만드세요.

모든 변경은 이 브라우저의 LocalStorage에 자동 저장되어, 새로 고침해도 그대로 남습니다.

## 여러 명이 함께 쓰기 (실시간 DB, 선택)

상단 `⚙️ 실시간 DB 연결`에서 무료 Firebase Realtime Database 주소를 넣으면 여러 사람이 같은 비서실을 실시간으로 함께 쓸 수 있습니다. 주소를 넣지 않아도 페이지는 로컬 모드로 그대로 동작합니다.

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트 만들기 (무료 Spark 요금제)
2. 빌드 → **Realtime Database** → 데이터베이스 만들기 → **테스트 모드**로 시작
3. 화면 위쪽의 `https://xxxx-default-rtdb.firebaseio.com` 주소를 복사
4. 페이지의 `⚙️ 실시간 DB 연결`에 붙여넣고 [연결하기]
5. 같은 주소를 친구에게 알려 주면 같은 비서실에 들어옵니다

> 테스트 모드는 누구나 읽고 쓸 수 있습니다. 중요한 개인정보는 올리지 마세요. 주소는 입력한 브라우저에만 저장됩니다.
