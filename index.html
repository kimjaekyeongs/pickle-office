📖 이렇게 써요

1. 방 이동 — 피클을 고르고 방(작업실·회의실·휴게실)을 클릭하거나 [방 이동] 버튼을 누르세요.
2. 상태 바꾸기 — 업무 중 / 회의 중 / 휴식 중에서 고르면 이름 옆 점 색이 바뀌어요.
3. 말풍선 — 하고 싶은 말을 적고 [말풍선 바꾸기]를 누르면 캐릭터 위에 그대로 보여요.
4. 회의실 — 회의실 아래에 안건을 적어 두고 하나씩 체크하며 회의할 수 있어요.
5. 동료 초대 — [+ 동료 피클 초대]에서 이름·자음·색을 골라 새 피클을 만드세요.
6. 여럿이 함께 — ⚙️ 실시간 DB 연결에 무료 Firebase 주소를 넣으면 친구 피클과 실시간으로 같이 써요.

⚙️ 실시간 DB 연결

지금은 이 브라우저에만 저장되는 로컬 모드예요. 아래에 무료 Firebase Realtime Database 주소를 넣으면 친구 피클들과 실시간으로 같은 비서실을 함께 쓸 수 있어요.

아직 연결하지 않았어요. 주소 없이도 이 페이지는 그대로 잘 동작합니다.
무료 DB 주소는 어떻게 만드나요?
  1. Firebase 콘솔에서 프로젝트를 하나 만듭니다(무료 Spark 요금제).
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기를 누르고, 위치를 고른 뒤 테스트 모드로 시작합니다.
  3. 데이터베이스 화면 위쪽의 주소(https://xxxx-default-rtdb.firebaseio.com)를 복사해 위 칸에 붙여넣고 [연결하기]를 누르세요.
  4. 같은 주소를 친구에게도 알려 주면, 친구 피클도 같은 비서실에 들어옵니다.

※ 테스트 모드는 누구나 읽고 쓸 수 있어요. 중요한 개인정보는 올리지 마세요. 주소는 이 브라우저에만 저장됩니다.

+ 동료 피클 초대

한글 자음 모양의 피클을 하나 더 만들어요. 이름과 자음, 색을 골라 주세요.
